API & provider setup

Firebase Authentication and Realtime Database power the account, wallet, deposit and order APIs. This is a starter integration, not an API key generator.

Order endpoint

POST /api/order
Authorization: Bearer <Firebase ID token>
Content-Type: application/json

{"service":"PROVIDER_SERVICE_ID","link":"https://example.com/post","quantity":100}

The server validates service IDs and quantity limits, calculates charges from provider rates, reserves wallet funds, stores order history, and refunds wallet funds if the provider rejects an order. Verify response formats before launch.

Required environment variables

FIREBASE_DATABASE_URL — https://sourajit-vfx-default-rtdb.firebaseio.com

FIREBASE_SERVICE_ACCOUNT_JSON — private service-account JSON, stored only in Vercel Environment Variables

ADMIN_PASSWORD — a new, strong unique admin password

ADMIN_SESSION_SECRET — random secret of at least 32 characters

SMM_PROVIDER_URL and SMM_PROVIDER_KEY — your real provider API details, if placing live orders

Never expose service-account JSON, admin credentials, or provider keys in frontend code or public commits. Revoke any key shared publicly and generate a replacement.

Firebase and manual deposits

Enable Email/Password in Firebase Authentication and set Realtime Database rules to deny direct client reads/writes. Upload database.rules.json in Firebase Console. Deposits are manual: an admin must independently verify the payment before approving it. Automatic payment confirmation is not included.
